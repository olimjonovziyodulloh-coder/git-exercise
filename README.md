# git-exercise

Practice repository for the Week 9 Monday Git exercises.

## Exercises

- **E1** — initialise a repository, add `index.html`, make the first commit.
- **E2** — create the `feature-style` branch, add `style.css`, merge it back into `main`.
- **E3** — add the `origin` remote and push both commits to GitHub.
- **Extra** — open and merge pull request #1 (`add-readme` → `main`).
